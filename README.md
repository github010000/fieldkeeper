# 필드키퍼 MVP — 비행장 경보를 즉시 행동으로

KAC 데모데이(2026-10-17) 시연용. 하드웨어 없이 「경보 → AI 판단 → 사람 승인 → 출동 → 기록」 한 바퀴를 웹 앱으로 돌린다.
**센서·로봇은 시뮬레이션, 판단·승인·기록은 실제 동작.** 공항은 가상의 지방공항이다(실제 공항 이름·도면을 쓰지 않는다).
공개 주소 = https://fieldkeeper.nabee.ai.kr · 시연용 MVP — **All rights reserved**(라이선스를 주지 않는다. 읽기는 자유, 가져다 쓰기는 허락 필요).

## 시연 방식(10-11 대장) — 폰 두 대
부스에 노트북을 둘 수 없어 **폰 화면이 기준**이다. 아이폰 13 미니 = 관제(대장이 들고 설명, 사파리) · 갤럭시 S23 = 현장(방문객이 승인, 크롬, 앱 고정).
두 폰이 같은 서버를 보므로 한쪽의 승인이 다른 쪽 지도에 1초 안에 보인다. 통신 = 두 폰 LTE 주, 행사장(헤이그라운드) 와이파이 예비.

## 구조
- 시연 = **장면 진행**: 관제 폰이 「다음 장면」으로 넘기고 → 시계가 장면 시각까지 빨리 가서 경보에서 멈추고 → 현장 폰이 **승인/보류**(사람이 결정) → 승인하면 장비가 지도 위로 이동 → 결과 · 기록. 네 장면 뒤 「분기 말」 기록표
- `src/scenario.ts` 네 장면(04:20 울타리 침입 · 05:00 활주로 이물질 · 08:57 북쪽 접근로 새 떼 · 12:53 드론) — 장면마다 「오늘(사실)」 · 추천 · 장비 경로 · 결과. 실제 공항 이름은 쓰지 않는다. 시뮬레이션 가정 = 지도 1칸 10m · 지상 로봇 15km/h · 드론 60km/h
- `src/airfield.ts` 가상 지방공항 평면도(SVG) — 실제 지방공항 규모(활주로 18/36 2,800m · 평행 유도로 A · A1~A5 · 계류장 · 로봇 대기소 · 북쪽 드론 거점 · 축척 막대). 특정 공항 도면이 아니다
- `src/timeline.ts` 시연 시계 — 회차의 장면 단계(phase)와 시작 시각에서 계산한다. 서버와 화면이 같은 `simClock` 을 쓴다
- `src/flights.ts` **실제 운항편** — 한국공항공사 「실시간 항공기 운항정보 조회_GW」(data.go.kr 15158625)의 `/arrival` · `/depart`. 장면에 들어갈 때 그 시간대의 실제 편을 붙인다(첫 출발 편 · 곧 착륙할 편 · 1시간 이착륙 수). 기준 공항 `FLIGHT_AIRPORT`(기본 CJJ, 화면에는 이름을 쓰지 않는다). 키는 **디코딩 키(+/=)면 인코딩해서** 넣는다 — 그대로 넣으면 30(등록되지 않은 키). 같은 조회는 10분 기억(개발 계정 하루 5,000건)
- `src/pages.ts` 한 페이지 · 역할 둘(폰에 기억, ☰ 메뉴에서 바꾼다): **관제**(지도 · 장면 카드 · 다음 장면) / **현장**(승인 요청 카드 · 승인/보류). 지도는 장면 현장으로 다가간다. ☰ = 역할 · 자유 경보(Q&A 대응용) · 처음으로(두 번 눌러야)
- `src/index.ts` API — `GET /api/state` · `POST /api/scene/next` · `POST /api/decide`(`{decision: approve|hold}`) · `POST /api/demo/start`(처음으로) · `POST /api/alerts`(자유 경보). 단계 전환은 읽은 단계 그대로일 때만(두 폰 동시 누름에도 한 번)
- 단추 잠금 — `DEMO_KEY`(`.dev.vars`, 커밋 안 함)가 있으면 POST 는 헤더 `x-demo-key` 가 맞을 때만. 폰은 열쇠 링크 `/?k=…`(역할까지 `&role=field`)로 한 번 열면 기억한다. 열쇠 없는 화면은 보기 전용
- `schema.sql` + `migrations/0002_scenes.sql` — runs(장면 단계) · incidents(경보 · 결정 · 도착, 시연 분) · alerts(자유 경보)

## 로컬
```
npm install
npx wrangler d1 execute fieldkeeper --local --file=schema.sql
npx wrangler d1 execute fieldkeeper --local --file=migrations/0002_scenes.sql
npx wrangler dev --ip 0.0.0.0 --port 8791     # 같은 와이파이의 폰에서 http://<mbp15 IP>:8791
```
화면 확인 = `node scripts/shot.mjs <주소> <폭> <높이> <출력접두> <ms,ms…>` — 헤드리스 크롬을 원격 디버깅으로 띄워 폰 화면을 흉내 내고 지정 시점마다 찍는다(JS 오류도 보고).
폭은 375×812(미니) · 360×780(S23) · 312(좁은 폭 점검). `--screenshot` 직접 호출은 이 맥에서 캡처 뒤 크롬이 종료하지 않고, `--window-size` 가 좁은 폭을 못 낸다.
